# One Stop Property Solutions — Frontend Design System

Welcome to the frontend design and UI repository for **One Stop Property Solutions**.
This repository contains the complete Next.js frontend, styling, animations, responsive layout, and UI components.

---

## 🚀 Quick Start for Developers

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Build for Production
```bash
npm run build
```

---

## 🎨 Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS with custom royal gold & midnight navy color palette
- **Animations**: Framer Motion & Anime.js
- **Icons**: Lucide React
- **Maps**: Leaflet & React-Leaflet
- **Internationalization**: i18next (English & Hindi support)

---

## 📁 Key Directories
- `app/` — Next.js App Router pages (Homepage, Properties, Locations, Services, Contact, etc.)
- `components/` — Modular, reusable UI components (Hero, Cards, Navigation, Footer, Filters)
- `data/` — Mock property listings, location data, and testimonials
- `context/` — Client state management (Consultation Bag, Authentication UI state)
- `public/` — High-resolution property photography, icons, and brand assets
